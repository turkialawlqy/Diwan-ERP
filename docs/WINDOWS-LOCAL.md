# تشغيل النظام وتحديثه على ويندوز (MAMP)

هذا الدليل لنسخة تعمل على جهاز ويندوز، مثل `C:\MAMP\htdocs\alostaz`. سكربت التحديث يسحب آخر نسخة من GitHub ويجهّزها كاملة، ويعمل بالنقر أو تلقائياً كل ساعة.

## المتطلبات (مرة واحدة)

| الأداة | ملاحظة |
|---|---|
| [Git for Windows](https://git-scm.com/download/win) | يتضمن Git Credential Manager لتسجيل الدخول إلى GitHub |
| [Node.js LTS](https://nodejs.org) | لبناء الواجهة |
| MAMP بـ PHP 8.2 أو أحدث | يكتشف السكربت PHP من `C:\MAMP\bin\php` تلقائياً |

لا حاجة لتثبيت Composer، فالسكربت ينزّله إن لم يجده.

## أول تحديث

1. ضع مجلد `deploy\windows` داخل `C:\MAMP\htdocs\alostaz` إن لم يكن موجوداً.
2. انقر نقراً مزدوجاً على `deploy\windows\update.bat`.
3. سيطلب ويندوز تسجيل الدخول إلى GitHub **مرة واحدة**، لأن المستودع خاص.

### ما يفعله السكربت

1. إن لم يكن المجلد مرتبطاً بـ Git:
   - يأخذ **نسخة احتياطية كاملة** إلى `C:\MAMP\htdocs\alostaz-backup-التاريخ`.
   - ثم يربطه بالمستودع.
   - يبقى كما هو: ملف `.env` والملفات المرفوعة في `storage`.
2. يضع النظام في وضع الصيانة، ثم يأخذ نسخة احتياطية لقاعدة البيانات (`alostaz-preupdate-…`). **إن فشل النسخ يتوقف التحديث** ويعود النظام كما كان. للتجاوز: `-Force`.
3. ينفّذ بالترتيب:
   - `composer install --no-dev`.
   - بناء الواجهة.
   - ترحيلات قاعدة البيانات.
   - مزامنة الصلاحيات.
   - تجهيز الكاش.
4. **إن نجح:** يعيد النظام للعمل.
5. **إن فشل بعد تغيير الكود** (ترحيل أو بناء):
   - **يبقى في وضع الصيانة** حمايةً للبيانات.
   - يطبع أمر الرجوع للإصدار السابق وأمر استعادة النسخة.
   - أو أصلح السبب وأعد تشغيل `update.bat` ليُكمل.
6. يضيف إلى `.env` مسار `mysqldump` الخاص بـ MAMP إن لم يكن موجوداً، ويعرض الإعدادات الجديدة التي لم تُضَف بعد.

**السجل:** `storage\logs\update.log`.

## التحديث التلقائي

انقر مرتين على `deploy\windows\install-auto-update.bat`:

- **التكرار:** يُنشئ مهمة مجدولة باسم `Alostaz Auto Update`، تفحص GitHub كل ساعة أثناء تسجيل دخولك إلى ويندوز.
- **إن وُجد تحديث:** تطبّقه خلال دقيقة أو اثنتين.
- **إن لم يوجد:** لا تغيّر شيئاً.
- **إن عدّلت ملفات الكود يدوياً:** لا يحدّث تلقائياً، حتى لا يضيع تعديلك. شغّل `update.bat` يدوياً، فيحفظ تعديلاتك جانباً بـ `git stash` قبل التحديث.

**ويسجّل أيضاً مهمتين ضروريتين تعملان كل دقيقة:**
- **`Alostaz Scheduler`:** المُجدول. يتولى النسخ الاحتياطي الليلي، وإبلاغ الهيئة بالفواتير المتأخرة، والقيود الدورية، والإهلاك، والمخصصات، والتنبيهات.
- **`Alostaz Queue`:** الطوابير. تتولى إرسال الفواتير لهيئة الزكاة، والبريد، والـ Webhooks، وتصدير البيانات.

بدونهما لا يعمل أي من ذلك.
- **التشغيل كمسؤول:** شغّل الملف **بالنقر الأيمن ← تشغيل كمسؤول** لتعمل المهمتان حتى بدون تسجيل دخول.
- **بدون صلاحية مسؤول:** تعملان أثناء تسجيل دخولك فقط.

**مطلوب في `.env`** (انظر `.env.windows.example`):

```
QUEUE_CONNECTION=database
SESSION_DRIVER=database
CACHE_STORE=database
APP_TIMEZONE=Asia/Riyadh
FORCE_HTTPS=false
SESSION_SECURE_COOKIE=false
TENANCY_REJECT_UNKNOWN_HOSTS=false
BACKUP_PASSWORD=كلمة-مرور-قوية
```

**للتحقق:** افتح «جدولة المهام» (Task Scheduler) وتأكد من وجود المهام الثلاث وأن آخر تشغيل ناجح.

**للإيقاف:** `powershell -ExecutionPolicy Bypass -File deploy\windows\uninstall-auto-update.ps1` (يحذف المهام الثلاث).

## خيارات متقدمة

```powershell
# فرع آخر (مثلاً بعد دمج التطوير في main)
powershell -ExecutionPolicy Bypass -File deploy\windows\update.ps1 -Branch main
# إعادة التجهيز دون تحديث جديد (مثلاً بعد مشكلة في البناء)
powershell -ExecutionPolicy Bypass -File deploy\windows\update.ps1 -Force
```

**إن حُذف الفرع الحالي بعد دمجه:** ينتقل السكربت تلقائياً إلى `main`.

## الاستعادة من نسخة احتياطية

- **ملفات النظام:** مجلد `C:\MAMP\htdocs\alostaz-backup-...` نسخة كاملة كما كانت قبل الربط. يمكن إعادة تسميته ليحل محل المجلد الحالي.
- **قاعدة البيانات والملفات المرفوعة:** النسخ في `storage\app\backups`. للاستعادة:

  ```
  C:\MAMP\bin\php\php8.x\php.exe artisan erp:restore alostaz-preupdate-YYYY-MM-DD-HHMMSS.zip
  ```

  يحتاج الأمر `BACKUP_PASSWORD` نفسه الذي أُنشئت به النسخة، ويضع النظام في الصيانة أثناء الاستعادة.

## ملاحظة عن MAMP

يكتب السكربت مسار `mysqldump` الخاص بـ MAMP في `.env` تلقائياً. إن كان `APP_ENV=production` فالنسخ **ترفض العمل بدون** كلمة مرور، فأضف إلى `.env`:

```
BACKUP_PASSWORD=كلمة-مرور-قوية
```
